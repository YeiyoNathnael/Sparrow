# Backend Documentation

## Overview

The backend is a **FastAPI** application that serves optimized school bus routes via a RESTful API. It reads route data generated by the RL4CO route optimizer and stores it in a SQLite database for efficient querying.

---

## Architecture

```
backend/
├── main.py              # FastAPI application entry point
├── requirements.txt     # Python dependencies
└── nexus.db            # SQLite database (auto-generated)
```

### Technology Stack

| Component | Technology | Purpose |
|-----------|------------|---------|
| Web Framework | FastAPI | High-performance async REST API |
| Database | SQLite | Lightweight persistent storage |
| ORM | Raw SQL | Direct database queries |
| CORS | FastAPI Middleware | Cross-origin requests for frontend |

## API Endpoints

### 1. Get Routes

```
GET /api/routes?peak_hours={boolean}
```

**Purpose:** Retrieve all optimized bus routes with their stop sequences.

**Query Parameters:**
- `peak_hours` (optional, boolean): Filter routes by peak/off-peak hours

**Response Structure:**
```json
{
  "routes": [
    {
      "id": "bus_0",
      "route_number": 1,
      "school_name": "school_1",
      "school_names": ["school_1", "school_20", ...],
      "student_count": 97,
      "distance_km": 25.64,
      "duration_minutes": 61,
      "polyline": [[25.093, 55.227], [25.094, 55.252], ...],
      "optimization_score": 89,
      "route_type": "peak_express",
      "start_time": "06:00",
      "status": "scheduled",
      "num_pickups": 3,
      "num_dropoffs": 20,
      "depot": [25.093, 55.227]
    }
  ],
  "total_routes": 13,
  "total_students": 998,
  "total_distance_km": 237.6
}
```

**Key Fields Explained:**

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique bus identifier (e.g., "bus_0") |
| `polyline` | array | Ordered sequence of [lat, lng] coordinates |
| `num_pickups` | int | Number of assembly point stops |
| `num_dropoffs` | int | Number of school stops |
| `depot` | array | Starting position [lat, lng] |
| `school_names` | array | List of schools served on this route |

**Polyline Structure:**
```
Index 0:              Depot (bus starting point)
Index 1 to num_pickups:   Pickup stops (assembly points)
Remaining indices:    Dropoff stops (schools)
```

### 2. Get Schools

```
GET /api/schools
```

**Purpose:** Retrieve all schools in the system.

**Response:**
```json
{
  "schools": [
    {
      "id": "school_1",
      "name": "School 1",

    }

```

---

### 3. Get Students

```
GET /api/students?limit={number}&offset={number}
```

**Purpose:** Retrieve student data with pagination.

**Query Parameters:**
- `limit` (optional, int): Maximum records to return (default: 100)
- `offset` (optional, int): Number of records to skip (default: 0)

## Database Schema

### Routes Table

```sql
CREATE TABLE routes (
    id TEXT PRIMARY KEY,
    route_number INTEGER,
    school_name TEXT,
    school_names TEXT,        -- JSON array of school names
    student_count INTEGER,
    distance_km REAL,
    duration_minutes REAL,
    polyline TEXT,            -- JSON array of [lat, lng] coordinates
    optimization_score REAL,
    route_type TEXT,
    start_time TEXT,
    status TEXT,
    num_pickups INTEGER,
    num_dropoffs INTEGER,
    depot TEXT                -- JSON array [lat, lng]
);
```

## Startup Process

1. **Load JSON Data**: On startup, the backend reads `optimized_routes.json`
2. **Initialize Database**: Creates SQLite database if not exists
3. **Populate Tables**: Inserts route data into the routes table
4. **Start Server**: FastAPI server starts on port 8000

```python
@app.on_event("startup")
async def startup_event():
    init_database()
    load_routes_from_json()
```

## Route Optimization Metrics

Each route includes optimization metrics:

| Metric | Description | Calculation |
|--------|-------------|-------------|
| `distance_km` | Total route distance | Sum of Haversine distances between stops |
| `duration_minutes` | Estimated travel time | distance_km × 2.4 (avg speed factor) |
| `optimization_score` | Route efficiency (0-100) | Based on distance reduction vs naive routing |
| `student_count` | Students served | Sum of students at all pickup points |
